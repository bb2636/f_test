---
name: VALID_ROLES 정확한 역할명
description: 역할 비교 문자열은 심사"사"/조사"사"이지 심사"자"/조사"자"가 아님 — 오타 시 조건 무음 실패
---

규칙: 코드에서 `user.role === "..."` 비교 시 정확한 값은 shared/schema.ts의
`VALID_ROLES = ["심사사", "조사사", "보험사", "협력사", "관리자"]`.

흔한 함정: "심사사"를 "심사자"로, "조사사"를 "조사자"로 쓰기 쉽다(문서/UI 본문엔
"심사자"가 담당자 호칭으로 등장해 헷갈림). 역할 비교에 "심사자"를 쓰면 항상 거짓이
되어 게이팅이 조용히 실패(에러 없이 동작만 안 함).

**Why:** 모바일 심사사 즐겨찾기 탭 숨김이 "심사자"로 비교해 배포 후에도 계속 노출됨.
**How to apply:** 역할 게이팅 추가/수정 시 반드시 VALID_ROLES 값과 글자 단위로 대조.
