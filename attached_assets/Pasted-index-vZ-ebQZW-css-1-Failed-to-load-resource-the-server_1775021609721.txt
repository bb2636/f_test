문제의 핵심을 찾았습니다. pgStore.set에서 DB 쓰기가 완료될 때까지 기다리는데, 배포 환경에서 DB 쓰기가 44초나 걸리고 있습니다. 세션은 이미 메모리 캐시에 저장되어 있으므로, DB 쓰기를 백그라운드로 처리하면 즉시 응답할 수 있습니다.
